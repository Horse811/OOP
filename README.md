# Описание проекта

## О проекте

Проект реализует систему учета товаров и категорий для интернет-магазина.

## Функционал

### Класс `Product`
- Хранение данных о товаре:
  - Название (`name`)
  - Описание (`description`)
  - Цена (`price`)
  - Количество (`quantity`)

### Класс `Category`
- Управление категориями товаров:
  - Название категории (`name`)
  - Описание (`description`)
  - Список товаров (`products`)
  - Автоматический подсчет:
    - Общего количества категорий (`category_count`)
    - Общего количества товаров (`product_count`)

## Установка

Для установки и запуска проекта необходимо выполнить следующие шаги:

1.  **Клонируйте репозиторий:**

    ```
    git clone https://github.com/Horse811/OOP.git
    ```

2.  **Перейдите в папку проекта:**

    ```
    cd OOP
    ```

3.  **Установите зависимости с помощью Poetry:**

    ```
    poetry install
    ```
4. **Запустите файл main.py, чтобы воспользоваться различными методами фильтрации и сортировки транзакций**

    ```
    python main.py
    ```

# Описание проекта

## Реализованный функционал

1. **Класс `Product`**:
   - Хранит данные о товаре: название, описание, цена, количество.

2. **Класс `Category`**:
   - Хранит название, описание и список товаров.
   - Автоматически подсчитывает:
     - `category_count` — общее количество категорий.
     - `product_count` — общее количество товаров во всех категориях.

3. **Тестирование**:
   - Проверка корректности создания товаров и категорий.
   - Проверка подсчёта категорий и товаров.
   - Покрытие тестами > 75% (проверяется `pytest-cov`).

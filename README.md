# Магазин товаров - Доработка архитектуры

## Новая функциональность

### 1. Абстрактный базовый класс
- Реализован абстрактный класс `BaseProduct` с обязательными методами:
  - `calculate_total()` - расчет общей стоимости
  - `__str__()` - строковое представление

### 2. Класс-миксин для логирования
- Добавлен `LoggingMixin`, который:
  - Логирует создание объектов с timestamp
  - Выводит переданные аргументы
  - Реализует `__repr__` для отладочного вывода

### 3. Обновленная иерархия классов

### Категории товаров
- Автоматический подсчет товаров
- Защищенное добавление товаров
- Строковое представление категории

### Ограничения
- Сложение только товаров одного типа
- Добавление только объектов Product и его наследников

## Установка

Для установки и запуска проекта необходимо выполнить следующие шаги:

1.  **Клонируйте репозиторий:**

    ```
    git clone https://github.com/Horse811/OOP.git
    ```

2.  **Перейдите в папку проекта:**

    ```
    cd OOP
    ```

3.  **Установите зависимости с помощью Poetry:**

    ```
    poetry install
    ```
4. **Запустите файл main.py, чтобы воспользоваться различными методами фильтрации и сортировки транзакций**

    ```
    python main.py
    ```

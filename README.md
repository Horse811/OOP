# Магазин товаров

## Реализованная функциональность

### Классы товаров
1. **Базовый класс Product**:
   - Хранение основных характеристик товара
   - Строковое представление
   - Сложение товаров одного типа

2. **Класс Smartphone (наследник Product)**:
   - Дополнительные атрибуты:
     - Производительность (efficiency)
     - Модель (model)
     - Объем памяти (memory)
     - Цвет (color)

3. **Класс LawnGrass (наследник Product)**:
   - Дополнительные атрибуты:
     - Страна-производитель (country)
     - Срок прорастания (germination_period)
     - Цвет (color)

### Категории товаров
- Автоматический подсчет товаров
- Защищенное добавление товаров
- Строковое представление категории

### Ограничения
- Сложение только товаров одного типа
- Добавление только объектов Product и его наследников

## Установка

Для установки и запуска проекта необходимо выполнить следующие шаги:

1.  **Клонируйте репозиторий:**

    ```
    git clone https://github.com/Horse811/OOP.git
    ```

2.  **Перейдите в папку проекта:**

    ```
    cd OOP
    ```

3.  **Установите зависимости с помощью Poetry:**

    ```
    poetry install
    ```
4. **Запустите файл main.py, чтобы воспользоваться различными методами фильтрации и сортировки транзакций**

    ```
    python main.py
    ```
